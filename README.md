## Level 1 Projects

### Project 1 - EDA on Retail Sales Data

**File:** Task_01(Dataset_01).ipynb, Task_01_(Dataset_2).ipynb

**Objective:** Perform exploratory data analysis on a retail sales dataset to uncover patterns, trends, and actionable insights for business decision-making.

**Key Highlights:**
- Data loading, cleaning, and preprocessing
- Descriptive statistics: mean, median, mode, standard deviation
- Time series analysis of sales trends over time
- Customer demographics and purchasing behavior analysis
- Visualizations using bar charts, line plots, and heatmaps

**Libraries Used:** pandas, numpy, matplotlib, seaborn

---

### Project 2 - Customer Segmentation

**File:** Task_02.ipynb

**Objective:** Segment e-commerce customers into distinct groups based on purchase behavior to inform targeted marketing strategies.

**Key Highlights:**
- K-Means clustering for customer grouping
- Descriptive statistics on purchase frequency and value
- Scatter plots and bar charts to visualize customer segments
- Insights and business recommendations per customer segment

**Libraries Used:** pandas, sklearn, matplotlib, seaborn

---

### Project 3 - Cleaning Data

**Files:** Task_03.ipynb, Task_03(Dataset_01).ipynb, Task_03(Dataset_2).ipynb

**Objective:** Demonstrate proficiency in data cleaning techniques across real-world messy datasets including NYC Airbnb data and YouTube trending video data.

**Key Highlights:**
- Handling missing values through imputation and removal
- Identifying and removing duplicate records
- Standardizing data formats and types
- Outlier detection and treatment
- Ensuring overall data integrity and reliability

**Libraries Used:** pandas, numpy

---

### Project 4 - Sentiment Analysis

**Files:** Task_04(Dataset_1).ipynb, Task_04(Dataset_2).ipynb

**Objective:** Build a sentiment analysis model to classify text data as positive, negative, or neutral using Twitter and Google Play Store review datasets.

**Key Highlights:**
- NLP preprocessing: tokenization, stopword removal, stemming
- Feature engineering using TF-IDF and Bag of Words
- Classification models: Naive Bayes and Support Vector Machine
- Visualization of sentiment distributions and results

**Libraries Used:** nltk, sklearn, pandas, matplotlib, seaborn

## Level 2 Projects

### Project 5 - Predicting House Prices with Linear Regression

**File:** Task_05.ipynb

**Objective:** Build a linear regression model to predict house prices based on relevant property features.

**Key Highlights:**
- Feature selection and engineering
- Linear regression implementation with Scikit-Learn
- Model evaluation using MSE, RMSE, and R-squared
- Visualization of predicted vs. actual values

**Libraries Used:** pandas, numpy, sklearn, matplotlib

---

### Project 6 - Wine Quality Prediction

**File:** Task_06.ipynb

**Objective:** Predict wine quality from chemical characteristics using multiple classifier models.

**Key Highlights:**
- Three classifier models: Random Forest, Stochastic Gradient Descent, Support Vector Classifier
- Feature analysis: density, acidity, and other chemical properties
- Model comparison and performance metrics
- Pattern discovery through Seaborn and Matplotlib visualizations

**Libraries Used:** pandas, numpy, sklearn, seaborn, matplotlib

---

### Project 7 - Fraud Detection

**File:** Task_07.ipynb

**Objective:** Develop a system to identify and flag fraudulent credit card transactions using machine learning.

**Key Highlights:**
- Anomaly detection on credit card transaction data
- Models: SVM, Decision Trees, Logistic Regression
- Handling class imbalance in the dataset
- Evaluation using Precision, Recall, F1-score, and AUC-ROC

**Libraries Used:** pandas, numpy, sklearn, matplotlib

---

### Project 8 - Unveiling the Android App Market

**File:** Task_08.ipynb

**Objective:** Analyze Google Play Store data to understand app market dynamics through data cleaning, categorization, and visualization.

**Key Highlights:**
- Data preparation: type correction and cleaning
- App category distribution analysis
- Metrics analysis: ratings, size, popularity, and pricing trends
- User sentiment analysis from review text
- Trend analysis and visualization

**Libraries Used:** pandas, numpy, matplotlib, seaborn, nltk

---

### Project 9 - Autocomplete and Autocorrect Data Analytics

**File:** Task_09.ipynb

**Objective:** Analyze and implement autocomplete and autocorrect algorithms in NLP to enhance text prediction accuracy.

**Key Highlights:**
- NLP preprocessing: tokenization, cleaning, n-gram modeling
- Autocomplete implementation using n-gram word and phrase prediction
- Autocorrect using edit-distance based spelling correction
- Performance benchmarking and algorithm comparison

**Libraries Used:** nltk, pandas, numpy, collections, matplotlib

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Afrin-mte/OIBSIP.git
cd OIBSIP
```

2. Install dependencies

```bash
pip install pandas numpy matplotlib seaborn scikit-learn nltk jupyter
```

3. Launch Jupyter Notebook

```bash
jupyter notebook
```

4. Open any `.ipynb` file to explore the project.

Alternatively, each notebook can be opened directly in Google Colab.
